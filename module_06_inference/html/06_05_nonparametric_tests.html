06_05 Nonparametric Tests: Ranks, Permutations and KS

Tests that do not depend on the shape of the data: robust to outliers and exact for small samples.

Key ideas

Mann-Whitney: $U_1=R_1-\frac{n_1(n_1+1)}2$; under $H_0$ $E[U]=\frac{n_1n_2}2$, $\mathrm{Var}(U)=\frac{n_1n_2(n_1+n_2+1)}{12}$; $U_1/(n_1n_2)=\hat P(X_1>X_2)$. Permutation test: $p=\frac{\#\{|T^*|\ge|T_{obs}|\}}{\#\text{relabellings}}$ (exact, any statistic). Sign test: Binomial$(n,\frac12)$. KS: $D=\sup_x|\hat F_1(x)-\hat F_2(x)|$, 5 % critical value $\approx1.36/\sqrt n$ (too large if parameters are estimated: Lilliefors). Efficiency of Wilcoxon against $t$: 0.955 (Normal), above 1 for heavy tails.

In plain words

  • Ranks forget how big an outlier is, only that it is the largest: put 30.2 or 3000 in the box and the rank test does not move.
  • A permutation test shuffles the labels to show what "no effect" looks like for any statistic you choose (means, medians).
  • The KS test compares whole distributions, so it can see a change of shape that a mean test cannot.
  • Estimated parameters make the usual KS critical value far too large: run the simulation to see it.

Each sample is truly Exponential. Testing it against an Exponential whose mean is estimated from the same sample gives a statistic D that is much smaller than for a fixed distribution: using the usual critical value rejects far less than 5 % of the time.

Where it is used

Statistics

Small, skewed or ordinal data, exact tests, Kruskal-Wallis, distribution comparison and goodness of fit.

Data science

A/B tests on heavy-tailed metrics, drift detection between training and production data with two-sample KS.

ML and AI

The Mann-Whitney U is the AUC of a score; permutation importance and permutation tests for models; calibration and shift checks.
