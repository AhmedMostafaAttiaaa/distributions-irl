06_03 Hypothesis Testing: the Core Ideas

Null and alternative, test statistic, p-value, Type I and Type II errors, power and sample size.

Key ideas

$z=\dfrac{\hat p-p_0}{\sqrt{p_0(1-p_0)/n}}$; $t=\dfrac{\bar x-\mu_0}{s/\sqrt n}$ ($n-1$ df). p-value $=P(\text{data at least this extreme}\mid H_0)$; reject if p $\le\alpha$. Type I error $=\alpha$; Type II $=\beta$; power $=1-\beta=\Phi\big(\frac{\delta\sqrt n}\sigma-z_{1-\alpha}\big)$. Sample size $n=\big((z_{\alpha}+z_{\beta})\sigma/\delta\big)^2$ (proportion: $\big(\frac{z_\alpha\sqrt{p_0q_0}+z_\beta\sqrt{p_1q_1}}{p_1-p_0}\big)^2$). Under $H_0$ the p-value is Uniform(0,1). $m$ tests: $P(\text{false positive})=1-(1-\alpha)^m$.

In plain words

  • The p-value asks: if nothing were going on, how often would we see data this extreme? It is not the probability that the null is true.
  • Two ways to be wrong: seeing an effect that is not there ($\alpha$) and missing one that is ($\beta$). Power is the chance of finding a real effect, and you must plan for it before collecting data.
  • Not significant does not mean no effect; check the power picture: with a small sample the two distributions overlap heavily.
  • Many tests, many false alarms: run the simulator with 20 tests to see how often pure noise gives a "discovery".

Where it is used

Statistics

Comparison of groups, regression coefficients, goodness of fit; power analysis for experiments and clinical trials.

Data science

A/B testing, guard-rail metrics, drift and monitoring alarms (the false-alarm rate is alpha).

ML and AI

Comparing models on a test set, feature relevance, detection systems whose Type I and II errors are false positives and false negatives (Module 10).
