09_08 Variational Autoencoders: the ELBO, the Reparameterisation Trick and the Latent Space

Learn a hidden code for the data, then generate new data from it: ELBO, Gaussian KL, reparameterisation and the beta trade-off.

Key ideas

ELBO $=E_q\ln p(x|z)-\mathrm{KL}(q(z|x)\|p(z))\le\ln p(x)$; gap $=\mathrm{KL}(q(z|x)\|p(z|x))$. Gaussian KL $\frac12\sum(\mu^2+\sigma^2-1-\ln\sigma^2)$. Reparameterisation $z=\mu+\sigma\varepsilon$. $\beta$-VAE: weight $\beta$ on the KL. Active unit: KL per dimension $>0.05$. Generation: decode $z\sim N(0,I)$.

In plain words

  • Encoder and decoder: the encoder guesses a hidden code for each data point, the decoder rebuilds the data from a code.
  • The KL term makes codes look like draws from $N(0,I)$, so new codes can be drawn and decoded into new data.
  • Reparameterisation moves the randomness out of the way, so ordinary gradients pass through the sampling.
  • Unused latent dimensions collapse to the prior; $\beta$ trades reconstruction against the information in the code.

The ELBO in a model where everything is known

Latent $z\sim N(0,1)$, observation $x\mid z\sim N(z,s^2)$. For an observed $x$ and any Gaussian encoder $q=N(m,v)$ the ELBO is exact, and $\ln p(x)=\mathrm{ELBO}+\mathrm{KL}(q\|p(z|x))$. Set $q$ equal to the true posterior to make the bound tight.

Worked example: reparameterised against score-function gradients

Gradient of $E_{z\sim N(\mu,\sigma^2)}[f(z)]$ with respect to $\mu$ for $f(z)=(z-3)^2+0.5\sin3z$. Both estimators are unbiased; their spread is not. Choose the number of samples per estimate and run 5,000 repeats.

Where it is used

Statistics

Data science

Nonlinear dimensionality reduction, anomaly detection by reconstruction, synthetic data generation and imputation.

ML and AI

Generative models of images and audio, latent diffusion, VQ-VAEs, disentangled representations, world models for reinforcement learning.
