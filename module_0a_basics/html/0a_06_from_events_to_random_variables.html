0a_06 From Events to Random Variables

A number for every outcome: the probability table, the expected value, the variance, and the long-run average.

Key ideas

Random variable $X$: a number attached to each outcome. PMF $p(x)=P(X=x)$, $\sum p(x)=1$; CDF $F(x)=P(X\le x)$. $E[X]=\sum xp(x)$; $\mathrm{Var}(X)=E[X^2]-\mu^2$; $\mathrm{SD}=\sqrt{\mathrm{Var}}$. $E[aX+b]=aE[X]+b$, $\mathrm{Var}(aX+b)=a^2\mathrm{Var}(X)$, $E[X+Y]=E[X]+E[Y]$, and for independent variables $\mathrm{Var}(X+Y)=\mathrm{Var}(X)+\mathrm{Var}(Y)$. The average of $n$ repetitions settles at $E[X]$ with SD $\sigma/\sqrt n$.

In plain words

  • A random variable is a number on each outcome; the PMF table says how likely each number is.
  • The expected value is the long-run average, not a value you will necessarily see (a die averages 3.5). Draw 200,000 samples and watch the running average lock on.
  • The SD measures risk: choose "sure 10 / coin / lottery" presets and edit the values: same mean, very different spread.
  • Averages add, variances add only for independent variables: compare X + X with two separate copies in the box.

Where it is used

Statistics

Every distribution is the PMF or density of a random variable; estimators such as the sample mean are random variables; moments and Chebyshev-type bounds.

Data science

Expected profit, cost and revenue per visit, risk as an SD or loss probability, KPIs as averages of random variables.

ML and AI

Expected loss minimised in training, rewards and bandit payoffs, mini-batch averages as estimates of expectations.
