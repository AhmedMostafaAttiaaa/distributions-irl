# Data for Module 09

- `SMSSpamCollection.tsv`: the SMS Spam Collection v.1 (5,574 English text messages labelled `ham` or `spam`), used in lesson 09_03. Source: UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/228/sms+spam+collection (Almeida and Hidalgo, 2011), licensed CC BY 4.0. Downloaded 2026-11-26 with `download_data.py`; tab-separated, label then message.
- All other lessons use random numbers from seeded generators (`numpy.random.default_rng`).
