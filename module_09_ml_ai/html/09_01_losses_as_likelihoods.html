09_01 Loss Functions as Likelihoods

MSE, MAE, Huber, pinball, cross-entropy and Poisson loss: each one is a noise distribution in disguise.

Key ideas

MSE $\leftrightarrow N$ (learns the mean); MAE $\leftrightarrow$ Laplace (median); pinball $\rho_\tau(r)=\max(\tau r,(\tau-1)r)\leftrightarrow$ asymmetric Laplace ($\tau$-quantile); BCE $\leftrightarrow$ Bernoulli; Poisson loss $\lambda-y\ln\lambda$. Sigmoid + cross-entropy gradient: $q-y$; with squared error: $2(q-y)q(1-q)$ (vanishes). Gaussian: $\hat\sigma^2=\frac1n\sum r^2$; Laplace: $\hat b=\frac1n\sum|r|$.

In plain words

  • Choosing a loss is choosing a noise model: bell curve, spiky Laplace, heavy-tailed $t$, coin flip, counts.
  • Each loss learns a different summary: mean, median or a chosen quantile.
  • Outliers pull the mean without limit, but only as one vote on the median.
  • Probabilities should be trained with cross-entropy: squared error stops learning when the model is confidently wrong.

Which constant does each loss pick?

Twenty points near 10 plus one extra point. Move the extra point and watch the minimiser of each loss: the mean follows it, the median and the robust losses hardly move. The pinball quantile $\tau$ sets the target quantile.

Worked example: training a sigmoid classifier from a bad start

One weight $w$, one positive example, $q=\sigma(w)$. Gradient descent with cross-entropy (gradient $q-1$) against squared error (gradient $2(q-1)q(1-q)$). Choose the starting weight and learning rate.

Where it is used

Statistics

Maximum likelihood, M-estimation and robust statistics, quantile regression and generalised linear models.

Data science

Forecasting with quantile losses, count models, robust regression, choosing metrics that match the question.

ML and AI

Regression and classification heads, language-model cross-entropy, Gaussian NLL heads, mixture density networks.
