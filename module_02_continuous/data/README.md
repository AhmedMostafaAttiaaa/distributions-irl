# Module 02 data

## tips.csv: restaurant bills and tips (lessons 02_01 and 02_02)

| Item | Value |
|---|---|
| Source | https://raw.githubusercontent.com/mwaskom/seaborn-data/master/tips.csv (the dataset behind `seaborn.load_dataset("tips")`; original data from Bryant and Smith, *Practical Data Analysis: Case Studies in Business Statistics*, 1995) |
| License | Distributed in the seaborn-data repository (https://github.com/mwaskom/seaborn-data); see the repository for terms. Used here for personal study only. |
| Download date | 2026-11-16 |
| Size | about 9.5 KB, 244 rows |

Columns: `total_bill` (bill in US dollars), `tip` (dollars), `sex`, `smoker` (Yes/No), `day` (Thur/Fri/Sat/Sun), `time` (Lunch/Dinner), `size` (party size).
